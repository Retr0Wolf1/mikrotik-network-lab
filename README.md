# MikroTik Network Lab

## Project Description

A virtual network infrastructure project created to demonstrate
practical skills in MikroTik RouterOS configuration.

## Network Structure

- Office VLAN — VLAN 10
- Server VLAN — VLAN 20
- Guest Wi-Fi — VLAN 30

## Implemented Features

- VLAN segmentation
- Firewall rules
- Internet access
- Port forwarding
- Network isolation
- Guest Wi-Fi restrictions

## Technologies

- MikroTik RouterOS
- WinBox
- VirtualBox
